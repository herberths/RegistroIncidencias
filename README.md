# RegistroIncidencias

## Propósito del Proyecto
Aplicación móvil desarrollada para el registro y gestión de incidencias, orientada a dar continuidad técnica y control de versiones al proyecto del curso.

## Herramientas Utilizadas
* **Entorno de desarrollo:** Android Studio
* **Lenguaje:** Kotlin
* **Interfaz:** Jetpack Compose / XML
* **Control de versiones:** Git y GitHub

## Estado Actual
* Estrcutura inicial del proyecto configurada y versionada.
* Pantalla base de registro implementada.
* Conexión con repositorio remoto en GitHub lista para futuras iteraciones.

## Cómo Abrir el Proyecto
1. Clona el repositorio: `git clone https://github.com/herberths/RegistroIncidencias.git`
2. Abre **Android Studio**.
3. Selecciona **Open** y navega hasta la carpeta del proyecto clonado.
4. Deja que Gradle sincronice las dependencias y ejecuta la aplicación.
